# videos

The films minos.io shows, served by GitHub Pages at `https://minos.io/videos/<file>`,
so browsers get `video/mp4` with range requests.

H.264 MP4 without audio, faststart: `<name>-h.mp4` is 1280 wide, `<name>-v.mp4` 720 wide
for phones, each with a JPG poster of the same name.

Every film has `-h.mp4`, `-v.mp4`, `-h.jpg` and `-v.jpg`.
